# 杜宾犬日常表情包 🐕🖤

108 张像素风杜宾犬透明底表情，已经逐张拆分并统一为 `512 × 512` PNG。

## 直接使用

- 在 [`emotes/`](emotes/) 中浏览、下载任意单张表情。
- 打开 [`gallery/index.html`](gallery/index.html) 查看完整图鉴。
- 需要一次取得全部文件时，下载 [`doberman-emotes-108-transparent-png.zip`](downloads/doberman-emotes-108-transparent-png.zip)。
- 支持 Git 仓库导入的工具，可直接使用本仓库地址；也可以执行：

```bash
git clone <本仓库地址>
```

## 文件结构

```text
emotes/      108 张透明底 PNG 成品
gallery/     可直接部署的网页图鉴
preview/     分页总览，便于快速检查
downloads/   完整离线包
manifest.json  原组图、行列与成品文件的对应关系
```

所有表情按原窗口图片的先后顺序，以及每张组图从左到右、从上到下排列。
